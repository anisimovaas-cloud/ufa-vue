# Квартира рядом — учебный проект на Vue 3

Одностраничное приложение для просмотра аренды в Уфе.

Сайт: https://kvartiry-ufa-vue-1711.adeptislet32.chatgpt.site
Данные получены с https://ufa.move.ru/ufa/arenda_kvartir/ — это сохранённая подборка, а не обновление в реальном времени.

## Файлы, которые нужно понимать

- `dist/index.html` — разметка. Директивы Vue связывают её с данными.
- `dist/app.js` — состояние приложения, фильтры и действия пользователя.
- `dist/style.css` — оформление и адаптация под телефон.
- `dist/listings.json` — объявления, которые собрал парсер.
- `parser.mjs` — сбор объявлений с Move.ru.
- `dist/assets/vue.js` — готовая библиотека Vue. Её код объяснять не нужно.

Vue подключён локально. Нет роутера, Pinia, сервера приложения и этапа сборки.
`cheerio` — единственная дополнительная библиотека, которую использует наш код: она помогает парсеру выбирать элементы HTML.

## Запуск

Установите Node.js 20 или новее. Распакуйте архив и откройте терминал в папке проекта.

1. `npm install` — установить библиотеки для парсера.
2. `npm run serve` — открыть локальный сайт. Адрес: http://localhost:8080.
3. В отдельном терминале `npm run parse` — обновить JSON. Затем обновить страницу браузера.

JSON уже приложен, поэтому для показа сайта не нужно снова собирать объявления.
Не открывайте index.html двойным щелчком: браузеру нужен локальный HTTP-сервер для загрузки модулей и JSON.

## Как объяснить Vue

1. `createApp({...}).mount('#app')` создаёт приложение внутри элемента с id app.
2. `data()` содержит данные: объявления, строку поиска, фильтры и избранное.
3. `v-model` записывает введённый текст или выбранное значение в переменную.
4. `computed.filtered` автоматически пересчитывает список при изменении данных и фильтров.
5. `filter()` проверяет каждое объявление: совпадает ли название, цена, комнаты, район и избранное. Все проверки соединены через `&&`.
6. `v-for` создаёт карточку для каждого найденного объявления; `:key` задаёт её идентификатор.
7. `v-if` показывает нужное состояние, например сообщение о пустом результате.
8. `@click` вызывает метод по нажатию. Двоеточие в `:src` или `:class` связывает атрибут с данными.
9. `localStorage` хранит идентификаторы избранного между перезагрузками. Это данные только текущего браузера.
10. Для подробностей используется обычный HTML-элемент `dialog`, который открывает `showModal()`. Escape закрывает его штатно.

## Как объяснить парсер

1. `fetch` скачивает HTML страницы аренды. Проверяем HTTP-статус и ограничиваем ожидание 20 секундами.
2. `load` из Cheerio позволяет искать элементы по CSS-классам, как в обычном CSS.
3. `.search-item.move-object` выбирает карточки. Список `selectedIds` содержит 9 объявлений, выбранных вручную по фотографиям. Парсер ищет их на первых двух страницах источника. Это учебная подборка, а не все объявления Уфы.
4. Из каждой карточки извлекаем название, цену, адрес и фото. `text()` получает текст, `attr()` — значение атрибута.
5. Регулярные выражения находят количество комнат, площадь и район. Отсутствующее значение сохраняем как `null`.
6. `Set` убирает повторяющиеся ссылки на фото. `new URL` делает относительные ссылки абсолютными. Каждое доступное фото скачивается в `dist/assets/photos`; в JSON записывается локальный путь. Поэтому показ сохранённых фото не зависит от доступности Move.ru. Неудачное скачивание пропускается.
7. Отдельно загружаем страницу объявления и читаем полное описание. Если она недоступна, оставляем краткий текст из карточки.
8. `JSON.stringify` превращает объект в JSON, `writeFile` сохраняет файл. Если карточек нет или источник недоступен, старый файл остаётся.

Парсер запускается отдельно в Node.js. В браузере собирать чужие страницы неудобно из-за ограничения CORS. Vue читает уже подготовленный JSON со своего сайта.
Парсер зависит от HTML-классов Move.ru: если сайт изменит разметку или заблокирует запрос, селекторы потребуется поправить. Обхода блокировок нет.

## Отсутствующие данные

Вместо отсутствующей цены, площади, района, комнат, фото и описания показываются подписи.
При фильтре по цене объявления без цены исключаются: невозможно определить, подходят ли они.
При фильтре по району объявления без района тоже исключаются. Без фильтров они видны.
Неудачная загрузка фото заменяет изображение заглушкой.

## Что показать на защите

1. Открыть список: видны 9 объявлений и счётчик.
2. Ввести `2-комн.` — показать поиск без учёта регистра.
3. Выбрать цену до 30000, две комнаты, район — показать совместную работу фильтров.
4. Ввести заведомо невозможную цену — показать пустое состояние. Нажать «Сбросить».
5. Нажать сердечко, открыть избранное, обновить страницу: сохранённая квартира остаётся.
6. Открыть «Подробнее», переключить фото, закрыть Escape.
7. Показать объявление без района и объяснить проверку отсутствующих полей.
8. Открыть parser.mjs и показать цепочку: fetch → Cheerio → объект → JSON.

Короткое вступление: «Я сделал одностраничное приложение на Vue 3. Данные собирает отдельный парсер на JavaScript. Во Vue реализованы поиск, фильтры, счётчик, избранное с сохранением в браузере и просмотр подробностей».
